# Contributing to the Speech Annotation Tool

Thank you for your interest in contributing! We welcome bug reports, feature requests, documentation improvements, and code contributions.

## Reporting bugs

Please open a [GitHub Issue](https://docs.github.com/en/issues/tracking-your-work-with-issues/using-issues/creating-an-issue) and include:

* A clear description of the problem
* Steps to reproduce the issue
* Any error messages or logs
* Your operating system (e.g. macOS, Linux, Microsoft Windows)
* A small example file or dataset, if it can be shared and is necessary to reproduce the problem

Please do not upload private, sensitive, or identifiable speech data to GitHub.

## Suggesting features

Feature requests and ideas are welcome. Please open a GitHub Issue describing:

* The problem or research workflow the feature would address
* How you envision the feature working
* Any relevant examples or use cases

## Contributing documentation or code

Documentation improvements are especially welcome. If you notice unclear instructions, missing information, or errors in the documentation, please open an issue or submit a pull request.

Before making a substantial code change, we encourage you to open an issue to discuss the proposed change.

For code contributions:

1. Fork the repository and create a new branch for your changes.
2. Make your changes and update relevant documentation.
3. Add or update tests when appropriate.
4. Check that existing functionality continues to work.
5. Open a [pull request](https://docs.github.com/en/pull-requests/how-tos/create-pull-requests/creating-a-pull-request) describing what you changed and why. Please keep pull requests focused on a single feature, bug fix, or improvement whenever possible.

## Questions and support

For questions about using the software, please first consult the documentation in the repository, including the README and the additional usage guides. If your question is not addressed there, you can open a GitHub Issue.

## Code of Conduct

Please read our [Code of Conduct](CODE_OF_CONDUCT.md). By participating in this project, you agree to follow these guidelines.
